Разработано веб-приложение с использованием JavaScript, React и Firebase.

- Авторизация пользователей с помощью их учетной записи Google.
- Управление доступом к другим компонентам в зависимости от того, авторизован ли пользователь или нет.
- Создание постов авторизованными пользователями.
- Добавление постов и информации об авторе в базу данных Firebase.
- Отображение постов.
- Удаление постов автором.
- Использование React Router.
- Базовая защита маршрутов.
